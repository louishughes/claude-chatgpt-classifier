A fresh cloud thread that had built none of it ran the full CI and the nightly gate, then captured every rich note the test suite renders (189 synthetic notes, 115 in the v2 template) without editing any repo file, and checked them with its own script against the note spec (`docs/plans/RICH_NOTES_GAP_ANALYSIS.md` §7, PRD FR-13). Report: `docs/evaluation/INDEPENDENT_REVIEW_2026-11-01.md`.

**Results:** CI green, 1,800 tests passed and 22 skipped (the Postgres tests can't run as root in the cloud container). Nightly gate: 8 pass, 2 review, 3 blocked; every blocked check needs real data or a paid model. The keyword list repeats near-duplicates ("cedar" next to "Cedar boards"), splits title phrases into single words, keeps filler words, and hides the tiers and the "left out because…" reasons the code already works out.

The synthetic half went ahead so the morning wasn't wasted.
