### 20:15 — DOC-001: one file per diary entry

**What:** New diary entries now go in `docs/diary/entries/`, one file each, and session-log entries go in `.agent-history/sessions/`. The two big files keep everything already written and point to the new folders.

**Why:** Every PR adds an entry, and on a busy evening four threads were adding theirs at the same spot. GitHub can't merge two edits to the same lines, so a PR that was green had to merge main again and wait another 13 minutes of CI. One PR lost that race twice. With one file per entry, two PRs never touch the same lines.

**Checks:**
```
two branches, each adding an entry file, merged one after the other: no conflict
```

**Talking points:**
- "Two people writing at the same line of the same log is a merge conflict, so the log became a folder of small files."
- A shared append-only file is a bottleneck for parallel work, even when it's only documentation.
