# Diary entries

One file per entry, named `YYYY-MM-DD-HHMM-<ticket>.md` (UTC), for example `2026-10-28-2015-DOC-001.md`. Filename order is reading order. Entries written before 2026-10-28 are in [`../BUILD_DIARY.md`](../BUILD_DIARY.md), and its rules still apply: no private content, what and why, a **Teach-back** line for a PR that changes code, and talking points.

Why one file each: every PR adds an entry, and when several threads merged on the same evening they all edited the same spot in one file and conflicted. Separate files never touch each other's lines.
