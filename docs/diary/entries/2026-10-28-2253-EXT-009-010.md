### 22:53 — EXT-009 and EXT-010: action items say where they stand and what they wait for

**What:** The spec (PRD FR-12) asks for actions with a status and dependencies. Before this, an action item in the note was just the sentence. Now each one says **Open**, **Reported done** or **Dropped**, citing the user's message that decided it, and **Waits for** another action when the user said one comes after the other.

**How it decides:**
- Only the **user's** later words count. "Done" from the assistant changes nothing, and silence means open, never done.
- "Reported done" needs a done word ("done", "finished", "fixed", "sorted", "did it"). The sentence can't be negated ("not done yet") or a condition ("paint it after the roof is fixed"). It also has to be about this action more than any other one in the chat, so "the shed roof is fixed" doesn't also close "paint the shed".
- "Dropped" needs explicit words ("skip it", "forget it", "not doing"). A bare "forget it" only counts if it's the very next thing the user says.
- A dependency is proposed when one user sentence names two of the chat's actions with "after", "once", "before" or "first ... then". The direction follows the words, and that sentence is the evidence. It's stored as a REC-002 link `depends_on` (migration 0032), as a **candidate** for review. A rejected link stops showing. Links never cross chats, and an assistant sentence never makes one.

**Design calls:**
- The ticket's review state `proposed` is REC-002's existing `candidate`, so no new state was added.
- Existing REC-002 link IDs are unchanged. The dependency detector has its own version (`ext-010-rules-v1`) in its link IDs.
- `action_status` takes an optional `others`, the chat's other actions, so a report is credited to the action it's most about. A tie leaves both open.

**Teach-back (`extraction/action_status.py`):** It reads only what the user said after an action. An action is marked done or dropped only when the user's own words say so about that action and no other. It also spots sentences like "paint the walls after the roof is fixed" and proposes that painting waits for the roof, quoting that sentence, for a person to accept or reject.
