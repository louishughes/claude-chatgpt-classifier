### 05:30 — ING-012: import a Markdown or text note so it's searchable and its links are found (#383)

**What:** ING-008 could already read a note into located blocks, but only to preview it. Nothing was stored, search only knew chat messages, and the link finder never saw a note. Now `ke import-doc PATH` takes a `.md`, `.markdown` or `.txt` file and:
- archives its bytes as an immutable snapshot (by SHA-256), through the same import ledger as chat exports, so a note import has a batch and a report too;
- stores the note as a **document**, identified by where it lives, with one **revision** per distinct content. The same bytes again add nothing. Changed bytes add a new revision, and the old one stays as evidence;
- stores every block with its character range and line locator (`L12-L15`);
- turns every URL into a link mention with the note as its source, in the same link registry as chat links. A YouTube link also points at its video, so the video's page (and its vault note) gets an "In your notes" section, and a video linked only from a note still shows in the video list.

`ke search` and `GET /search` return note hits in a separate `document_hits` list, with the file name and locator. Chat hits are unchanged. Only each note's current revision is searchable, so a changed note never shows up twice. The source file is only ever read.

**Decisions (delegated by Louis's /goal: "use your own judgement"):**
- New tables (`source_documents`, `document_revisions`, `document_blocks`, `document_links`, migration 0035) instead of making chat link rows nullable. Every existing query that joins links to messages stays correct without being touched.
- Search filters (speaker, date, vocabulary term, one chat) are about messages, so a filtered search returns no note hits. It doesn't return unfiltered ones.
- A note's identity is a fingerprint of its resolved path, never the path itself. Moving the file makes it a new document. That is the safe direction: nothing is merged on a guess.
- A purge of a chat keeps any link target or video that a note still mentions.

**Teach-back (`importer/text_documents.py`):** It reads a note once, stores an exact copy, and keeps the note as one document with a new version each time its bytes change, so re-importing the same file adds nothing. Every paragraph and heading is saved with the lines it came from, and that's what lets search say "found at L3". Every web link in the note goes into the same link list as chat links, so a YouTube video shows every chat and every note that mentions it.
